# Conversor de Moedas

Projeto de conversor de moedas desenvolvido para realizar conversões em tempo real entre:

- 💵 Dólar (USD)
- 💶 Euro (EUR)
- 💷 Libra Esterlina (GBP)
- 🇧🇷 Real Brasileiro (BRL)

O sistema possui uma interface simples, moderna e responsiva, permitindo que o usuário visualize rapidamente os valores convertidos.

---

# ⚙️ Como executar o projeto

## Clone o repositório

```bash
git clone https://github.com/marcelodevv/convert-coin
```

## Acesse a pasta do projeto

```bash
cd convert-coin
```

## Execute o projeto

Abra o arquivo:

```bash
index.html
```

Ou utilize a extensão **Live Server** no VSCode.
